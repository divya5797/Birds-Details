This is a simple frontend project about birds, created using HTML, CSS (and optionally Bootstrap).
It displays different types of birds, their images, and provides a clean navigation menu for easy browsing.


Features:-
Navigation Menu – Home, About, Help, and Service sections.

Bird Types List – Includes Barn Swallow, Cliff Swallow, Cave Swallow, Tree Swallow, and Violet-Green Swallow.

Bird Images – Displays pictures of different birds such as Swallow, Parrot, Robin, and Pigeon.

Buy Buttons (Dummy) – Each bird card has a "Buy" button for demonstration purposes (no backend connection).

Responsive Layout – Works on different screen sizes.

Footer Section – Social media icons for "Connect with us".


 Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and layout

(Optional) Bootstrap – For responsive design and styled buttons

Note:- This is a frontend-only project.
The "Buy" buttons are just placeholders and do not perform any real purchase action.
